# .zrx対応の調査状況（2026-09-30）

**未対応です。利用者の実ファイルが必要です。**
公開情報で見つからないことは、形式が存在しないことの証明ではありません。

今回確認した一次資料・配布物：

- https://www.zampler.de/ ：公式機能説明とダウンロード先。SFZ/REXの説明がある。
- https://www.zampler.de/upload/Zampler-3-Beta-Windows.zip ：公式配布パッケージ。アーカイブ内に.zrxサンプルはなく、含まれるプラグインの文字列には `.fxp`、`.fxb`、`.sfz;*.rex` が確認できた。文字列調査だけで対応形式全体は断定しない。
- https://www.zampler.de/upload/Zampler-3-Beta-macOS.zip ：DMG入りパッケージ。外側ZIPに.zrxサンプルなし。DMG内部は未調査。
- https://www.zampler.de/upload/Zampler_Demo_Digital_Bass.zip ：公式デモライブラリのファイル一覧を確認。.fxb、.fxp、.sfz、WAVを含むが.zrxは見つからなかった。

上記ファイルは調査用に取得しただけで、本ソースZIPには含めていません。
.zrxのバイナリ配置、圧縮方式、音声参照、フィルター／FX設定へのマッピングは特定していません。

次に必要なもの：

1. 実際に使いたい `.zrx` を1個以上。
2. 可能なら作成／読み込み可能なソフト名とバージョン。
3. 同じファイルを本家で開いたときの音色名や主要パラメーター値。
4. 外部サンプルを参照している場合は対応するSFZとサンプルのフォルダー構成。

データを得た後の実装手順：ファイル識別・構造解析 → 確認できたフィールドのみマッピング →
未知バージョンを明示拒否 → 欠落サンプルや非対応設定を報告 → 実ファイルによる回帰テスト。
仕様を確認する前に、独自形式を.zrxと称したり、ファイル名の文字列から音色を推測してロードしたりしない。
