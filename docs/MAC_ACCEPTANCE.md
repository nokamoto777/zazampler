# M1 / macOS Golden Gateでの受け入れ確認

このチェックは未実施です。macOS用コードの実機確認を完了するまで、本番制作の唯一の音源として置換しないでください。

1. `bash scripts/build-macos.sh` を実行。C++/Objective-C++、AUv3、VST3、AU、Standalone、二つのテストを完了させる。
2. `file` で本体と `.appex` と `.vst3` がarm64を含むことを確認する。
3. `codesign --verify --deep --strict` で署名確認。Sandbox entitlementsにuser-selected read-onlyとapp-scope bookmarksが含まれることを確認する。
4. `bash scripts/install-macos.sh`、`bash scripts/validate-macos.sh`。AUv3は別ホストで実際に選択する（auvalだけではAUv2/AUv3のどちらを検証したか曖昧）。
5. DAWのVST3トラックでDemo/Sine.sfzを選択し、MIDIノート69で440 Hzを確認する。
6. AUv3対応ホストでも別途同じ試験を実施。GUIのフォルダー選択が開くことを確認する。
7. SFZとサンプルを選択フォルダーの別サブフォルダーに配置し、相対パス参照を確認する。
8. 44.1/48/96 kHz、64/128/512/1024サンプルで演奏。サステイン、ピッチベンド、ノートオフ、Panic、チャンネル変更を確認する。
9. 画面操作中／音色切替中にホストが停止しないことを確認。読み込み中のMIDIは保持しない。
10. SFZと音量等を設定してDAWを保存し、DAWを完全終了して再起動。再選択なしでサンプルへアクセスできるかAUv3とVST3それぞれで確認する。
11. フォルダーを移動／外付けドライブを一旦外す。失敗表示と再選択による回復を確認する。
12. Loading終了後にオフライン書き出し。リアルタイム演奏との差を確認する。
13. 各FXタブを操作してパラメーターが保存・復元されることを確認する。LP/HP/BP/Notch、EQ、サチュレーション、コーラス、フェイザー、ディレイ、リバーブを個別に試す。
14. BPM60/120で四分音符ディレイが1秒/0.5秒になること、Panicで残響が消えることを確認する。
15. 実際のZampler音色で本家と比較し、未知opcode、サンプル欠落、エフェクト差を記録する。
